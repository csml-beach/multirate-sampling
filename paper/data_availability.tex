\section*{Data availability}

Code, experiment scripts, and manuscript sources for this study are maintained
in a public GitHub repository.\footnote{\url{https://github.com/csml-beach/multirate-sampling}}
Public benchmark inputs used in the predictive experiments are derived from
standard UCI datasets; all other benchmark targets are synthetic and are
generated directly by the repository code. Generated figures, metrics, and
supplementary animation artifacts are available in the project repository for
reference and reproduction.
